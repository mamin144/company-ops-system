## 2. النطاق: ما نُفذ وما لم يُنفذ

### ما نُفذ

| المجال | التنفيذ |
|---|---|
| **استعادة اللغة قبل الرسم (pre-paint)** | سكربت inline في `index.html` يقرأ `localStorage['cos-proto-lang']` ويضبط `lang/dir` على `<html>` **قبل** تحميل أي JS — إعادة تحميل محفوظة-الإنجليزية لا تومض بالعربية RTL. يعكس مفاتيح ملف `direction.ts` نفسها (PERSISTENCE_KEY + dirFor) داخل try/catch. |
| **جلسة غير صالحة ← لا وميض محتوى محمي** | `useState` initializer في `auth.tsx` يستدعي `readSessionValidated()`: جلسة محفوظة هويّتها لا تُعيد مستخدمًا حيًّا من المحوّل ← تُحذف من `sessionStorage` ولا تُستعاد (المسار يذهب إلى `/login` مباشرةً). |
| **تنظيف الجلسات الميتة عند الركوب** | `refresh()` يُسقط أي جلسة هويّتها لا تُقابل مستخدمًا حيًّا (`sessionStorage.removeItem` + `setUser(null)`)، وeffect عند التحميل يستدعيها مرة واحدة. |
| **العودة إلى المسار المقصود** | Guard يحمل `state={{ from: loc }}` عند إعادة التوجيه؛ Login يستخرج `dest`: **داخلي فقط** (يبدأ بـ `/` واحد ولا يبدأ أبدًا بـ `//`، يحفظ `?search`) وإلا الوجهة الافتراضية؛ بعد الدخول `nav(dest)`. |
| **عنوان الصفحة لكل لغة** | `document.title = dict[lang].docTitle` في `i18n/setup` — يتتبع التبديل فورًا. |
| **ترجمة نصوص القوقعة المتبقية** | شريط العلامة (`protoTag`)، `aria-label` مسار التنقل (`crumbsAria`)، `aria-label` حوار قائمة الأوامر (`paletteTitle`)، وأسماء تبويبات الأجنحة في Settings/Admin/Stock — مفاتيح i18n جديدة في `ar.ts`/`en.ts` (تطابق نوعي مفروض عبر tsc). |
| **اختبارات المرحلة 5** | `verify/phase5.spec.ts` — 9 اختبارات (تفصيلها في §5). |

### ما لم يُنفذ (بوعي ضمن القواعد)

- **لا مزوّد مصادقة جديد، لا استراتيجية توكن جديدة، لا آلية تخزين جلسة جديدة** — نفس تدفقات المرحلة 3 المعتمدة مع اكتمال قواعد تهيئتها.
- **لا نظام i18n موازٍ** — نفس حزمة `i18n/` الموجودة (مفاتيح جديدة فقط).
- **لا إعادة تصميم بصري للقوقعة** — الشكل المعتمد من المرحلة 3 لم يُمَس؛ قصّة الشريط العلوي على الهاتف (§8.1) **سُجلت** ولم تُصلح بصمت لأن أي إصلاح يترتب عليه قرار تخطيط معتمد لدى المالك.
- **لا تعديل إطلاقًا في `apps/web`** الإنتاجية.
- **لا commits/pushes/stashes** — التغييرات البرمجية داخل `docs/` (untracked كما هي دائمًا).

## 4. الوظائف والقرارات الموثقة

### 4.1 ما تغيّر تجربة المستخدم

1. **إعادة تحميل محفوظة-الإنجليزية لا تومض بالعربية/RTL** — اللغة تُستعاد قبل أول فرشاة، ثم يتولى React نفس الحالة دون ازدواج شرطي.
2. **عنوان التبويب يتتبع اللغة** (عربي/إنجليزي حرفيًا) فورًا مع التبديل.
3. **جلسة تالفة تسلك المسار الصحيح:** فتح النموذج بجلسة هويّتها غير موجودة يهبط على شاشة الدخول نظيفة — بلا ومضة شل محمي وبلا أخطاء كونسول.
4. **العودة للمسار المقصود:** من يزور `/reports?q=1` غير مسجَّل ثم يسجل الدخول، يهبط في `/reports?q=1` — والروابط غير الداخلية (`//…`) تُرفض داخليًا إلى الوجهة الآمنة.
5. **القوقعة كليًّا ثنائية اللغة:** شريط العلامة، مسار التنقل (a11y)، حوار قائمة الأوامر (a11y)، تبويبات Settings/Stock/Admin، وعنوان الصفحة.

### 4.2 دلالات "انتهاء الجلسة" و401/403 في النموذج

- **"منتهية"** في نموذج المحاكاة = هويّة الجلسة لا تُقابل مستخدمًا حيًّا في ذاكرة المحوّل الهمي ← تسقط عند التهيئة ويُنظّف مخزنها عبر `refresh()` عند التحميل. **لا علم تخزين جديد**؛ الدلالة عقدية: "جلسة لا تُقابل استعلامًا حيًّا = غير مسجل".
- **رفض الصلاحية = نتيجة معتمدة من نوع `{ ok: false, code: 403, error }`** — لا مسار 401 في النموذج لأن المصادقة التظاهرية بلا كوكيز ولا تعتمد على تبادل طلبات HTTP. مُختبَر في `verify/phase5.spec.ts` (viewer ← `/admin` يرى صندوق الرفض، والرسالة نفسها ثنائية اللغة). **عند الربط الإنتاجي لاحقًا** يبقى سلوك 401 (تنظيف جلسة ثم إعادة توجيه للدخول مع `state.from`) معتمدًا على هذه الدلالة نفسها — لم يُثبَت الآن لأن عقده الواقعي (كوكيز/توكن خادم) غير موجود بعد في النموذج، وإدخاله الاصطناعي كان اختراعًا بلا سند.
- تغطية القبول الصريح للمرحلة مكتملة: انتهاء الجلسة بدلالتها المعتمدة هنا، العودة للمسار، وسلوك 403.

### 4.3 العيب المكتشف والمصلَّح في المحوّل (ضمن الحدود)

`userApi.get()` كان `clone(users.find(...))` — و `clone(undefined) = JSON.parse(JSON.stringify(undefined))` يرمي `SyntaxError` (`JSON.parse("undefined")`). أي مستدِع يتحرَّى عن مستخدم محذوف — شاشة الدخول بعد حذف مستخدم تجريبي، أو قراءة جلسة محفوظة هويّتها حُذف صاحبها — كان سينهار بدل استلام `undefined`. الإصلاح بأصغر صورة:

```ts
get: (id: string): MockUser | undefined => {
  const u = users.find((x) => x.id === id);
  return u ? clone(u) : undefined;
},
```

سلوك كل المستدعين الحاليين محفوظ حرفيًا: للسجلات الموجودة النتيجة مطابقة تمامًا، والتغير الوحيد هو عدم الرمي بعد الآن لغير الموجود.
