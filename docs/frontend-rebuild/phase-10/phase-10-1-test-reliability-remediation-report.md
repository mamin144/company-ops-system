## ج) تفصيل سدّ كل فجوة (الإصلاح + الدليل)

### GAP-01 — `verify/admin.spec.ts` (حساب المستخدم: مسار التحقق)
- **السبب:** الاختبار القديم نقر «حفظ التعديلات» ببريد بصيغة غير صالحة متوقعًا `errBox`، بينما التشريح المعتمد للمرحلة 9 هو خطأ حيّ أثناء الكتابة (`span.err[role=alert]`) وزر حفظ **معطّل** حتى تصحيح النموذج — لا يوجد مسار إرسال عند فشل الصلاحية، فتعلّق النقر على زر معطّل حتى انتهاء مهلة الاختبار.
- **الإصلاح:** تأكيد الخطأ الحيّ (`صيغة البريد غير صالحة`) + `toBeDisabled` للحفظ؛ ثم بريد صالح → `toBeEnabled` → حفظ → `errBox = مسجل بالفعل` (مرآة محقق API لربط محجوز `layla.hassan@example.org`) ثم إكمال دورة الإنشاء الحالية بلا أي تراخٍ.
- **إصلاح مواقع (locators):** `getByLabel('البريد التلكوتي *')` لم يعد يطابق لأن `aria-label` الفعلي «البريد التلكوتي» — استخدمت `{ exact: true }` بلا نجمة.
- **الدليل:** التشغيلان 1→2 أعلاه؛ **7/7 ناجحة**.

### GAP-02 / GAP-03 — `verify/archive.spec.ts` (استبدال + استيراد CSV)
- **السبب:** مسارات `C:\Users\PC-01\AppData\Local\Temp\opencode\...` خاصة بجلسة مطوّر — لا تعمل مستقلّة.
- **الإصلاح:** عمود ثابت `FIXTURES` في رأس الملف عبر `path.dirname(fileURLToPath(import.meta.url))`، واستبدال جميع المسارات (×4)؛ إنشاء `verify/fixtures/replacement.txt` و `verify/fixtures/import-mixed.csv`.
- **تصميم CSV مشتق من التأكيدات الموجودة** (لا تعديل تأكيدات): ترويسة `العنوان,رقم المستند,التصنيف,النوع,الحالة`؛ صف صالح (`مستند مستورد صالح/DOC-IMP-01/مستخلصات/مستخلص`)؛ صف عنوان فارغ (DOC-IMP-02)؛ صف مكرر برقم البذرة DOC-198 (بحالة فارغة ليصل فحص التكرار)؛ صف حالة مجهولة `nonsense` (DOC-IMP-03) → يحقق سيُضاف 1/سيُتخطى 3، ومربع التكرار الواحد، وفشل إعادة الخريطة يظهر 4× «العنوان مطلوب».

### GAP-04 — `verify/i18n.spec.ts:84` («الاتجاهان يعرضان نفس الشاشات»)
- **إعادة تشغيل دون تغيير أولًا (إلزامية):** فشل وحيدًا عند 32.4s — مُستنسخ.
- **التشخيص المثبَت:** الاختبار الواحد يمشي 14 صفحة × اتجاهين = 28 تنقّلًا كاملًا + 28 تبديل لغة؛ مهلة الاختبار الافتراضية (30s في التشغيل بلا إعدادات) مضمونة الفيضان. مع `--timeout=90000` نجح الوحيد في ~70–80s. الخطأ الظاهر `locator.count: Target page ... closed` ضجيج تفكيك بعد القتل، لا عيب في محددات/تأكيدات.
- **الإصلاح داخل المخزن:** `test.setTimeout(90_000)` كأول سطر في جسد هذا الاختبار فقط، مع تعليق يوثق القياس. (ملاحظة: محاولة أولية عبر كائن التفاصيل `test(title, {timeout}, fn)` لم تُطبَّق — الكائن يدعم tag/annotation فقط — لذا اعتُمد `test.setTimeout()`.)
- **الدليل:** التشغيلان 6 (إثبات خارجي) → 7 (إصلاح دائم) → 8 (**28/28 كامل الملف**).
